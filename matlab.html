Fixed Income

  • NSS_estim Main script for estimating Nelson-Siegel-Svensson (NSS) yield curve parameters using different numerical methods.
    • LSQfit Performs nonlinear least squares calibration of NSS parameters to observed market prices.
    • discflow Calculates discounted cash flows for bonds using the NSS spot rate curve.
    • NSS Implements the Nelson-Siegel-Svensson functional form for the continuous spot rate curve.

FX Options

  • FXoptionPDF Computes the implied probability distribution for an FX rate using spline interpolation of volatility in delta space (Bloomberg-style approach).
    • smile_delta Maps strike to implied volatility via delta-based interpolation of the volatility smile.
    • bscall2 Garman-Kohlhagen pricing function for FX call options.
    • hessian Computes the second derivative numerically to extract the implied density.

Utilities

  • getYahooData Function to retrieve financial data from Yahoo and load it into MATLAB table format.
